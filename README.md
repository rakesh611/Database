# Database Learning

A practical **Database Administration + DevOps + Kubernetes/OpenShift Handbook**.

This repository is designed to take a learner from database fundamentals to Linux administration, DBA operations, troubleshooting, backup/recovery, monitoring, Kubernetes/OpenShift deployment, and production-level problem solving.

## Learning Path

```text
Understand
    ↓
Install
    ↓
Configure
    ↓

    ↓

    ↓

    ↓

    ↓

    ↓

Automate
    ↓

    ↓

```
